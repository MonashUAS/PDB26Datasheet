  \section{Features}
  \begin{itemize}[label=--, itemsep=6pt, topsep=4pt, parsep=0pt, leftmargin=*]
    \item Wide input voltage range: \SI{16.8}{\volt} to \SI{50.4}{\volt}
    \item Safety factor of 1.25
    \item Harmonic filtering with overvoltage protection
    \item Current and voltage monitor
    \item 12S and 4S input support
    \item No dedicated avionics battery required
    \item Onboard telemetry output
  \end{itemize}

  \section{Applications}
  \begin{itemize}[label=--, itemsep=6pt, topsep=4pt, parsep=0pt, leftmargin=*]
    \item Fixed wing UAV
    \item Flight controller supply
    \item Control-surface servo power
    \item Payload, video and datalink
    \item Vision camera
    \item Current and voltage telemetry
  \end{itemize}
\end{minipage}%

  \section{Description}
  The power distribution board (PDB) is a multi-board device that takes the
  raw power from LiPo batteries and distributes it to the various peripherals
  on the aircraft. The goal of Avionics PDB 2026 is to create a versatile PDB
  that can power the essential avionics and various projects on a fixed-wing
  aircraft.

  \vspace{0.5em}
  The board is designed to be able to take in both a 12S and 4S input to
  eliminate the need for a dedicated avionics battery. There are various
  subcircuits on each board which are detailed in this document. This document
  serves to explain the overall design process of the PDB, covering
  requirements, schematic design, layout design and any iterations on circuits.
\end{minipage}
